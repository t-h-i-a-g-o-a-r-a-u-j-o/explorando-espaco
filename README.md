# 🌌 Explorando o Espaço

Projeto web desenvolvido para praticar conceitos de **HTML, CSS e JavaScript**, criando uma experiência visual e interativa sobre astronomia.

O site apresenta páginas sobre **buracos negros, nebulosas e grandes estrelas**, com layout responsivo, navegação entre páginas e visualização ampliada de imagens através de modal.

## 🚀 Demonstração

🔗 **Acesse o projeto online:**

https://t-h-i-a-g-o-a-r-a-u-j-o.github.io/explorando-espaco/

## ✨ Funcionalidades

- Navegação entre múltiplas páginas
- Layout responsivo para desktop, tablet e celular
- Cards interativos
- Galeria de imagens
- Modal para ampliação das imagens
- Fechamento do modal pelo botão, clique externo ou tecla `Esc`
- Navegação por teclado nas imagens da galeria
- Design inspirado em temática espacial
- Estrutura HTML semântica
- Efeitos de hover e transições em CSS

## 🔭 Conteúdo do projeto

### 🕳️ Buracos Negros

Página com informações sobre:

- Horizonte de eventos
- Disco de acreção
- Jatos relativísticos

### 🌌 Nebulosas

Página com informações sobre:

- Nebulosas de emissão
- Nebulosas planetárias
- Nebulosas de reflexão

### ⭐ Maiores Estrelas

Apresentação de algumas estrelas conhecidas por suas grandes dimensões:

- UY Scuti
- Stephenson 2-18
- Betelgeuse

## 🎯 Objetivo do projeto

O **Explorando o Espaço** foi desenvolvido como parte dos meus estudos em desenvolvimento web.

O objetivo foi colocar em prática a criação de uma aplicação web com múltiplas páginas, trabalhando **estrutura semântica, responsividade, organização de código e interatividade com JavaScript**.

O projeto também integra meu portfólio no GitHub e demonstra conhecimentos práticos em desenvolvimento front-end.
